# Translations

This directory holds compiled translation files for the Space Lightplay plugin.

WordPress.org translation system (translate.wordpress.org) generates the `.po`
and `.mo` files automatically from the source strings in the plugin. They are
downloaded and updated on each WordPress site individually — there is normally
nothing to commit here by hand.

Translators: please contribute via the official translation portal:
https://translate.wordpress.org/projects/wp-plugins/space-lightplay/
